# Sprint OS

A personal operating system for work and life: weekly sprints, tasks, notes, links and files in one context graph, with AI running the rituals (sprint close, retro, rollover, triage). It is **local-first**: your data lives on your device, and the app is fast, private and works offline.

This is a from-scratch rebuild of [Sprint](https://github.com/dymitrkorlotian/sprint), the web app (Next.js and Supabase), which keeps running while this one is built.

## Status

**Architecture.** No code yet. The founding architecture is being written as [ADR-0001](docs/decisions/), status *Proposed*. Building starts once it's accepted, after Sprint's testing phase (5 Oct – 1 Nov 2026) and its UI/UX pass.
